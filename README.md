# Superstore Sales Dashboard

## Project Overview
This Power BI dashboard analyzes Superstore sales performance across different regions, categories, segments, and shipping modes.

## Key Insights
- Total Sales: 1.6M
- Total Profit: 175K
- Total Orders: 22K
- Technology category generated high sales
- Standard Class was the most used shipping mode

## Dashboard Features
- Regional Sales Analysis
- Monthly Sales & Profit Trends
- Category & Sub-category Insights
- Segment-wise Performance
- Interactive Filters

## Tools Used
- Power BI
- DAX
- Data Visualization
- Data Cleaning
